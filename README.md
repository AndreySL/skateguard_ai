## О проекте

SkateGuard AI — это веб-приложение, которое автоматически обнаруживает скейтбордистов на видео или изображениях в запрещенных зонах (памятники, ступеньки административных зданий, площадки с табличками "No skating" и т.д.). Проект использует предобученную модель YOLOv8 для детекции объектов и сохраняет историю нарушений с возможностью генерации отчетов.

---
## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/AndreySL/skateguard_ai
cd skateguard_ai
```
### 2. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 3. Установка зависимостей

```bash
python app.py
```

## Основной функционал

-  Загрузка изображений и видео
-  Обработка потока с веб-камеры
-  Детекция скейтбордистов с помощью YOLOv8
-  Определение нахождения в запрещенной зоне
-  Сохранение истории запросов в JSON
-  Генерация отчетов (PDF / Excel)
-  Простой веб-интерфейс на HTML/CSS/JS

## Используемые технологии

| Компонент       | Технологии                          |
|----------------|--------------------------------------|
| Язык бэкенда   | Python 3.10+                         |
| Фреймворк      | FastAPI                              |
| Нейронная сеть | YOLOv8 (YOLOv8n, YOLOv8n-seg)        |
| Фронтенд       | HTML, CSS, JavaScript                |
| Отчеты         | ReportLab (PDF), openpyxl (Excel)    |
| Хранение данных| JSON                                 |
